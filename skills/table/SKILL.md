# Table Skill

## Purpose
Use this skill when the source contains structured rows, records, comparisons, or datasets.

## Recommended Components
Prefer:
- table
- card
- heading
- metric

## Rules
1. Preserve row and column values exactly.
2. Use a table when multiple records share the same fields.
3. Do not invent missing rows or values.
4. Use metrics only for clearly represented summary values.
