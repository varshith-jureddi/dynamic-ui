# Dashboard Skill

## Purpose
Transform structured business, product, financial, operational, or project data into a useful analytics dashboard.

## When to Use
- KPIs and metrics
- business performance
- operational health
- project status
- trends and comparisons
- categorical distributions

## Dashboard Principles
- Put important KPIs first.
- Use StatGrid for a compact KPI row when appropriate.
- Use charts only when they reveal a useful pattern.
- Use tables for detailed records.
- Use Progress for completion or target metrics.
- Use Status for operational state.
- Use ActivityFeed for recent events.
- Use Insight only when supported by source data.
- Avoid unnecessary components and duplication.
- Never invent data.

## Recommended Components
- StatGrid
- Metric
- Chart
- Table
- Progress
- Status
- ActivityFeed
- Insight
