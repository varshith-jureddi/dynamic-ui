# Timeline Skill

## Purpose
Use this skill when the source contains milestones, dates, chronological events, phases, or project progress.

## Recommended Components
Prefer:
- timeline
- heading
- card
- text

## Rules
1. Preserve source dates when available.
2. Keep chronological order when the source provides it.
3. Do not invent dates.
4. Use a timeline only when chronology is meaningful.
## Skill Identity
This skill is a chronological presentation skill and can be combined with Dashboard or Visualization when appropriate.
