# Documentation Skill

## Purpose

Use this skill when the input is technical documentation, specifications, structured reference material, or implementation notes.

## When to Use

Use when the content contains:
- technical sections
- specifications
- implementation guidance
- APIs or configuration information

## Recommended Components

Prefer:
- heading
- text
- list
- card
- tabs

## Rules

1. Preserve technical terminology from the source.
2. Organize long material with headings.
3. Use lists for enumerated requirements.
4. Do not invent technical facts.
5. Do not execute or generate source code.
