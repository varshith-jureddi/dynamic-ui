# Visualization Skill

## Purpose
Choose the simplest chart that communicates a real pattern in the supplied data.

## Rules
- Line: time-series trends.
- Area: trend plus magnitude.
- Bar: category comparison or ranking.
- Pie/Donut: small categorical distributions only.
- Never use pie/donut for time series.
- Never invent or alter chart data.

## Recommended Components
- Chart
