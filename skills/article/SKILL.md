# Article Skill

## Purpose
Use this skill when the input is primarily prose or documentation.

## Recommended Components
Prefer:
- heading
- text
- list
- card

## Rules
1. Preserve the meaning of the source.
2. Do not invent facts.
3. Use headings to organize long content.
4. Use lists for enumerated information.
## Skill Identity
This skill is an Article/Prose presentation skill and can be combined with Timeline or Table when appropriate.
