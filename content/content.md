# Adaptive Dashboard

This is the Phase 1 content source. Replace this Markdown file with the pre-existing project content, or point `CONTENT_FILE` at a JSON or Markdown file inside the project.

## Content foundation

The application reads project content directly and normalizes it into a common internal representation. No upload workflow is used.

- JSON is supported.
- Markdown is supported.
- Content is rendered without AI rewriting.
- The normalized model is independent of the source format.

> Phase 1 establishes the content foundation. Adaptive AI layouts are introduced in later phases.
