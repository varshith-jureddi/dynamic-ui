Get dynamic dashboards and layouts that provide information in a intuitive and interactive way that helps understanding the data with the help of ai
the dynamic aspect of the project helps reducing the rigidity of traditional ui and make the process of gaining insights alot easier


## Authors

- [@varshith-jureddi](https://github.com/varshith-jureddi)


## Features

- Dynamic Dashboards and layouts
- personalised UI
- Intuitive data analysis


## Tech Stack


**Client:** Next, React, TailwindCSS

**Server:** Node, TypeScript


## Run Locally

Clone the project

```bash
  git clone https://github.com/varshith-jureddi/dynamic-ui
```

Go to the project directory

```bash
  cd dynamic-ui
```

Install dependencies

```bash
  npm install
```

Start the Frontend

```bash
  npm run dev
```

Add API key to the .env file to use AI
